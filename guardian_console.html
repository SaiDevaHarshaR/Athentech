Guide for common problems

AI answers fail: check provider quota and model status. Excel shows zero: inspect collection metric and compare SQL source values. PDF fails: check browser/Chromium and report permissions. Admin login fails: check admin credentials and service logs. DB unreachable: check only that client's SQL connection.

Escalation rule

If a step doesn't resolve the problem, download the support report and give it to the appointed developer. Do not run unknown SQL, change production schema, or copy patient information into tickets.
