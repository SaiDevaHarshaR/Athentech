Quick, admin-friendly troubleshooting for the most common incidents.

Excel export failed

Run a self-check. If only monthly exports fail, test a shorter date range, inspect schema diagnostics, and compare values with SQL/Sahasra.

AI Agent failed

Check whether the error is from database access, LLM provider, or a schema mismatch. Instant non-LLM reports may still work.

Admin or backend issue

Look for API connectivity, reverse proxy problems, or authentication failures. If Guardian login fails, verify the FastAPI route before checking UI code.

Client schema changed

Refresh only that client’s profile cache, open diagnostics, and inspect rejected config pins or missing columns before escalating.
